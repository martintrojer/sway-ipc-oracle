# sway IPC oracle results

Curated compositor results for the sway IPC oracle belong here as `<compositor>.toml`.

Sway and swayward results compare every captured sway field. i3 results compare
only the shared fields in i3's pinned IPC protocol. They report shared-field
value differences as `differs` and sway-only fields as `not applicable`; these
counts are not a pass rate. `sway-ipc/applicability.toml` records the field sets
and source citations.
